---
name: Set-model grouping
description: Fraction Quest design rule for visual fraction-of-a-set models.
---

For fraction-of-a-set visuals, arrange objects into a number of equal groups matching the denominator. Make each group’s objects easy to count; the numerator identifies how many groups are selected. Do not imply equal groups when the total cannot be divided evenly.

**Why:** The user asked to organize arrays into logical groups by 3s, 4s, and other denominators so children can see what the fraction numbers represent.

**How to apply:** Use this convention in lesson examples, generated practice, worksheet diagrams, and printable models. Preserve an ungrouped fallback only when an equal division is not valid.
