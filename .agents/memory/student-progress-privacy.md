name: Student progress privacy
description: User-selected identity model for connecting student progress to educator reports.
---

For educator reports, the user's selected setup is: class codes, no student names, and progress saved online.

**Why:** the user chose this option when deciding how student progress should connect to educator reports.

**How to apply:** Keep student identity out of educator progress reporting. The current GitHub sign-up flow uses usernames and optional display names; treat that as a divergence from the stated choice, not a silently superseding decision, and surface it before changing the account model.
