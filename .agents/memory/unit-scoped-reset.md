---
name: Scoped progress resets
description: Preserve family-level and aggregate learner data when clearing one unit's attributable activity.
---

A unit reset should remove only data attributable to lessons in that unit: lesson completion and evidence, unit-specific game scores and challenges, related skill reviews, and matching topics in daily practice. Keep family/account settings, broader assessments, and aggregate rewards or activity that cannot be reliably attributed to the selected unit.

**Why:** Families need to replay one unit without losing unrelated work or settings; aggregate XP and streaks are shared across the course rather than owned by one unit.

**How to apply:** When adding resettable data, include a unit reset only when its ownership can be established from the selected unit. Persist the scoped result through the normal account-sync path so signed-in devices receive the same snapshot.
