---
name: Read-aloud controls
description: The product rule for Listen controls in lesson content.
---

Give each logical lesson section one Listen control at its header. It should read the complete section, not a sentence or fragment at a time. Do not attach Listen buttons to individual text fragments.

**Why:** The user found many Listen buttons confusing and asked for one control per section.

**How to apply:** Group a question, worked answer, explanation, hint, feedback block, or worksheet prompt under one header-level control. Avoid rendering the same hint twice when feedback already includes it.
